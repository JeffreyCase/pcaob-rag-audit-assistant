Saved benchmark example · Q05Supported answer

What completeness problem did EY's 2024 inspection identify in the population of new and modified contracts reviewed for revenue recognition?

Saved model response

The inspection finding indicated that EY did not evaluate whether the first control was designed to identify a complete population of new and modified contracts for the second control's revenue-recognition review [EY, 2024 inspection, PDF p. 20]. In audit terms, the downstream review could not be relied upon without first addressing the completeness of the population feeding it [EY, 2024 inspection, PDF p. 20].

From report to reviewed answer

  1. Extract the relevant pagesRead Part I.A in six public reports and preserve report and PDF page references.

  2. Retrieve evidenceSearch text passages with keyword and semantic retrieval. For cross-firm questions, search each firm separately and combine the results.

  3. Generate or refuseGive Gemini only the retrieved passages, with instructions to cite substantive claims and decline unsupported questions.

  4. Verify against the sourceAssess retrieval, answer support, citations, usefulness, and refusals through automated checks and human review.

Scope and professional judgment

Six reports, two firms, three inspection years, and one audit topic form a small, deliberately limited corpus. Inspection findings cannot establish an overall ranking of firms.

No practicing-auditor pilot, measured research-time savings, or integration with a firm's methodology has been completed. Source verification and qualified professional review are still required.

Project contribution

Team origin.
Independent portfolio work.

I developed this prototype as part of a four-person Rutgers MAcc project using extensive AI coding assistance. ChatGPT generated the Python implementation; I directed and reviewed the workflow, ran and tested the prototype, verified outputs against PCAOB sources, evaluated the results, and presented the architecture.

After the course submission, I independently converted the work into this public portfolio edition with AI assistance. My teammates and I shared the academic project's audit framing, written deliverables, and final presentation.

The repository includes the original Python pipeline and instructions for optional live queries. This website presents saved examples so the project can be explored without running a model.
